# 小行星带与近地轨道空间站

太阳系导航新增「小行星带」与「空间站」，均支持独立观测、锁定、自由航行、跃迁及存档恢复。手机导航栏可横向滚动选择。

- 主小行星带的示意粒子环绕太阳，覆盖 2.1–3.3 AU；谷神星位于 2.77 AU，平均半径为 473 km，是进入带区的导航目标。近景岩块使用原创不规则几何模型与批量渲染。粒子、轨道间隙和谷神星附近的岩群用于游戏可视化，密度不是天文实测值；近景小岩块为装饰，不参与碰撞，谷神星沿用行星碰撞和着陆规则。
- 近地轨道空间站位于地球表面上方 400 km，包含模块舱体、通信天线、八片太阳能翼与航标灯。它是跨度 120 km 的原创科幻设施，固定轨道位置为示意，不是国际空间站的真实尺寸或实时位置。当前支持近距离观测，暂不支持对接或站内活动。
- 空间站保留实体碰撞，但不产生行星重力或独立的 1000 km 行星限速区域。附近的环境与发动机限制仍以地球计算；跃迁从空间站朝太空的一侧抵达，避免进入地球。不能用选择空间站绕过地球附近的跃迁限制。
- 小行星带只显示在太阳系的太空场景，沿用独立太空/地表渲染，切换恒星系后隐藏。

新增素材完全由程序几何生成，不增加贴图下载或外部素材依赖。
