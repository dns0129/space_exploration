# 星际探索网站与自动发布

网站首页介绍太阳系、半人马座 α、参宿四与原创回声裂隙目的地、自由驾驶和跃迁，在线游戏为同一个源码构建出的真实 3D 游戏，无需下载 ZIP。网站部署地址为 `https://dns0129.github.io/space_exploration/`，在线游戏路径为 `game.html`。只有 GitHub Pages 配置完成且部署成功后，这些地址才可访问。

## 首次启用

在 [仓库 Settings → Pages](https://github.com/dns0129/space_exploration/settings/pages) 的 **Build and deployment → Source** 选择 **GitHub Actions**。只需设置一次。

如果此前的部署因 Pages 未启用而失败，在 [Actions](https://github.com/dns0129/space_exploration/actions/workflows/deploy-site.yml) 打开 **Deploy 星际探索 website**，选择 **Run workflow**，或重新运行失败的任务。工作流不需要额外的密钥；它使用仓库自带的 `GITHUB_TOKEN` 和 Pages 身份令牌。

仓库需允许 GitHub Actions 与 GitHub Pages。仓库或组织配置的环境保护规则可能使部署等待审批；请以 Actions 的实际结果为准。

## 每次更新

任何提交推送到 `main` 都会触发 `.github/workflows/deploy-site.yml`：安装锁定依赖，执行后端与动力学检查，构建首页和游戏，再部署到 Pages。取消尚未完成的旧部署，优先发布最新一次提交。构建失败时保留之前成功发布的网站。

等 Actions 的部署任务成功后刷新网站，即可使用新代码。通常需要几分钟，提交成功并不代表部署已经完成。网站首页底部显示对应的 Git 提交；`version.json` 提供完整提交与构建时间，用来核对线上代码。

已经打开的页面每分钟、以及回到前台时检查新版本；检测到新的提交会显示“新版本已上线”，点击“刷新体验”加载新版本，避免打断正在驾驶的玩家。没有 Service Worker 或离线缓存，JavaScript 与 CSS 文件名包含内容哈希。主页与游戏的路径均以 `/space_exploration/` 为前缀。

在线网站托管静态文件，航行存档使用当前浏览器本机存储，不托管 Node.js 后端。刷新后进入驾驶舱，点击“恢复存档”继续。旧下载包、本机服务器和 Pages 各自属于不同的浏览器来源，存档不自动共享；删除浏览器数据会删除本机存档。需要服务器持久存档时仍可使用完整下载包。

## 落地离舱与徒步探索

行星观测站可先选择“放置飞船”或“放置人物”，再点击星球上的地点，直接开始地表驾驶或徒步。支持所有具有固体地表的岩石行星、卫星与系外行星；恒星、巨行星与空间站禁用放置。选点时可拖动/缩放，Esc 取消，切换天体取消；所选地貌与实际落地画面共用固定球面材质和高度场。直接放置后的飞船与人物继续使用原有存档、返舱和起飞功能。

右上角相机按钮或 P 开启摄影：画布覆盖整个视口，观测面板、驾驶与徒步仪表、触屏按钮、通知和返舱光环全部隐藏。Enter 保存 PNG；P/Esc 或双击画面恢复界面，手机双击画面退出。`npx playwright test tests/observatory-tools.spec.ts` 验证桌面与手机真实选点、地表停稳、人物保存恢复、全屏无界面及 PNG 导出。

在岩石行星或卫星着陆后，按 **E** 或点击 **离开飞船**，即可离开飞船。**W/A/S/D** 行走、**Shift** 奔跑、**空格** 跳跃，方向键或拖动场景观察，**C** 切换第一/第三人称；手机提供相应的行走、奔跑、跳跃和返舱按钮。人物落地并走回停泊点 **12 m** 内后，按 E 或点击 **返回飞船** 返舱，再按 L/R 起飞。

地球、月球、火星和土卫六分别使用 9.81、1.62、3.71 和 1.35 m/s² 重力；相同起跳速度下，低重力天体有更高、更长的跳跃，极低重力天体另有宇航服回落辅助。脚底碰撞、局部地形与轨道表面共用高度函数。徒步时飞船留在原地，起飞、飞船推力、对准目标和跃迁暂不可用；暂停冻结人物运动。网站本机存档与下载包均保存人物位置、速度、朝向、视角和腾空状态；旧版有效的着陆、徒步存档会迁移到统一地形，保留表面方向和离地高度。

## 本地开发和验证

```sh
npm run dev -- --port 5173 --strictPort
```

开发时 `site.html` 为网站首页，`index.html` 为游戏入口；主页“立即启航”会直接进入自由航行。这里的本机端口仅用于内部开发，不作为公开游戏链接。

```sh
npm run build:site  # 类型检查及网站构建，输出 dist-site/
npm run test:site   # 构建后，验证部署路径下的桌面与手机浏览器行为
```

`scripts/build-site.mjs` 保持原有 `npm run build` 与独立 HTML 导出的工作方式。网站专用构建将首页输出为 `index.html`、游戏输出为 `game.html`，并让游戏跳过后端 API，直接使用本机存档。`VOYAGER_SITE_BASE` 可设置其他合法的部署路径，默认 `/space_exploration/`；构建版本来自 `GITHUB_SHA`，本地则来自当前 Git 提交。

验证会实际加载完整构建，检查主页和手机导航、目的地选择与进入观测、行星像素、直接驾驶、推力、本机保存和刷新恢复、跨恒星系跃迁及背景切换、大气与地表着陆、起飞及着陆存档恢复、新版本刷新以及项目路径下的资源。要求没有 HTTP 错误、浏览器错误或静态托管中的后端 API 请求。截图保存在忽略的 `test-results/site/` 中。

`npx playwright test tests/walking.spec.ts` 另行验证桌面和手机的离/返舱、实际行走、跳跃按键边沿、停泊飞船固定、远处返舱限制、暂停及徒步存档恢复，并保留地球徒步和月球跳跃截图。各重力下的轨迹、碰撞与存档输入校验同时由 `npm run test:server` 中的动力学测试覆盖。

## 画面素材

首页地球、火星与土星 PNG 是现有游戏渲染器生成的原始截图，未引入额外图库；地表贴图作者与许可继续见 [ASSETS.md](../ASSETS.md)。各航区使用同一真实原生 8K 银河全景，保留独立方向和亮度；紧凑/软件渲染设备默认 4K。游戏直接采样经纬纹理，避免生成低分辨率立方体贴图。太阳、行星和卫星使用实测高清影像；没有全球影像的海王星小卫星、海卫二以及半人马座三颗恒星和比邻星 b/c/d 使用公开许可的 4K 高清概念图，并在 ASSETS.md 中逐一标注。火星、卫星和半人马座天体的贴图在接近或观测时才从 `textures/` 下载。系外行星地表为探索示意，c/d 标注为候选行星。首页没有运行第二个 WebGL 场景，完整 3D 渲染只在进入游戏后启动。

土星环与首页土星预览使用相同的冰粒薄层材质：按 D/C/B/A/F 环分区计算光学厚度、视角透光、正反面散射和相互投影；细条带、冰/尘色差与颗粒按像素过滤。没有环系图片贴图，物理参考的密度及成分仍为程序化示意。`npx playwright test tests/saturn-rings.spec.ts` 用实际 WebGL 像素验证密集环遮光、稀薄环透射、掠射光程及土星与环系的相互阴影。

参宿四航区目前仅包含恒星，支持观测、近观、跨系统跃迁与本机存档恢复。公开版与离线包均提供原生 8K 表面艺术示意和紧凑设备使用的 4K 版本；复用 8K/4K 银河全景并单独设置方向和亮度。参宿四无法地表着陆，暂不添加行星或伴星。


在线版与离线版共用独立的导航和引擎面板：导航可收起，下方滑条选择五档 1–100、100–1000、1000–10,000、10,000–50,000、50,000–150,000 km/s 航速，默认 100 km/s。目标速度与当前速度分别显示，调速后逐渐加减速。只有距离实际固体地表 10 km 以内时才切换为 1–1000 m/s 的低空滑条；低空和太空预设独立保存，出低空后恢复太空预设。旧 O 轨道控制已由滑条替代，旧存档迁移到新档位。独立星球内场景继续接管地表、蓝天、多层云与太阳盘，切换时暂停非当前模式的生成和资源处理。

火星与月球使用原生 8192 × 4096（8K）表面影像，在接近或进入观测时才加载，启动地球场景不下载这两张大图。触屏、低内存、GPU 纹理上限不足 8K 或大图下载失败时，回退到已有原生 4096 × 2048（4K）影像。原始来源与 SHA-256 记录在 ASSETS.md 和 provenance.json，8K 版本保留原始像素尺寸并以 JPEG 质量 90 编码，未将 4K 图片放大。



当前星球材质已恢复到增强升级前版本。近地表只绘制一个完整封闭球面，集中细分观察者附近的网格，不叠加地表补片、AI 材质或额外岩石。五档推进和导航保持当前版本。

近地、落地与徒步的完整球面沿用原有影像配色和中性照明。火星红色、月球灰色及地球绿色陆地的桌面/手机画面回归见 `tests/surface-colors.spec.ts`。


## 回声裂隙 · 原创虚构航区

首页目的地与游戏“恒星系统”均可进入回声裂隙。这里包含中央脉冲星、气态巨行星维尔、两颗大型岩石卫星塔拉萨与烬岩，以及碎裂巨型行星残冕和碎裂卫星裂片。系统、轨道、距离与物理参数均为虚构；脉冲星采用 18,000 km 的艺术放大视觉半径，残冕与裂片的半径为残骸视觉包络。

塔拉萨的海岸、水系和烬岩的干燥地质使用固定的共用高度场；轨道观测、地表网格、着陆与徒步碰撞采样同一地貌。水系设定由潮汐与地下热支持。两颗完整岩石卫星可着陆、放置和徒步，脉冲星、气态巨行星及碎裂残骸禁止着陆和放置，并显示原因。系统内与跨系统跃迁、途中取消及存档恢复继续沿用本机存档机制。

回声裂隙背景保持银河全景的风格，并使用独立尘埃带、星点与色彩细节；它与其余真实航区背景分别选择。

脉冲星采用蓝紫等离子纹理与白色边缘辉光，倾斜磁轴上有细长蓝白双极喷流，赤道周围有灰金尘雾环。残冕与裂片保留近圆球形轮廓，不规则主裂带带有断续分叉、岩桥、宽窄变化和错层断壁。真实厚度的断层露出暗色冷却岩壳与红橙炽热流道，熔融内部具有视线方向的多层深度。漂浮碎块直接裁自同一曲面岩壳并保留原材质坐标；七级颗粒尺度、岩层法线与低反光的粗糙岩石质感在近景逐级细化。两套外观按用户参考图重新制作程序化三维模型；观测与自由航行共用，支持绕行查看。`tests/pulsar-reference.spec.ts` 与 `tests/shattered-reference.spec.ts` 验证实际 WebGL 图像、裂隙近景及桌面/手机观测页。
