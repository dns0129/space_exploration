# 大气、地表与着陆

**最新 `voyager-warp.zip` 已同步本次高清星球贴图（太阳、行星、全部卫星与半人马座天体使用高清影像或 4K 高清概念图，近距离不再出现贴图马赛克）、连续跃迁拉近、飞船比例与连续大气过渡。** 离线包内嵌全部贴图，体积约 45 MB。

下载 **`voyager-warp.zip`**，完整解压，将 `voyager-warp.html` 拖入 Chrome 或 Edge。点击顶部“自由航行”，按 W 出发，方向键转向（鼠标不操控飞船），Shift 加速，空格刹车，C 切换视角，J 启动跃迁引擎，L 自动着陆/起飞/中止。手机使用触屏驾驶按钮。

恒星系统菜单支持太阳系与半人马座 α；可访问南门二 A/B、比邻星及比邻星 b/c/d，跨系统跃迁、光年距离和背景自动切换均可离线使用。c/d 为候选，系外行星和半人马座背景是探索示意。

卫星导航包括月球及四颗巨行星的 25 颗主要卫星，共 35 个天体。距表面 1000 km 内通常最高 100 km/s；100 km 内朝太空可用行星引擎离开，近地仍禁止跃迁。制动时有琥珀色减速脉冲。

独立 HTML 包含全部程序、样式与高清素材，可离线驾驶，使用本机存档。使用 4K 银河背景与真实太阳系尺寸、平均日距。选择导航目标后可对准航向，或启动跃迁，经蓄能、航道和减速抵达附近，支持暂停、保存和恢复。

包内也有后端程序。安装 Node.js 24 LTS 后双击 `启动航行.bat`（Windows），或运行 `bash 启动航行.sh`（macOS/Linux），然后在本机浏览器打开 `http://127.0.0.1:3000/`。也可直接运行 `node server/server.mjs --standalone`。后端不需要安装 npm 依赖，存档保存在 `data/` 中。

浏览器需要支持 WebGL 2 并启用图形加速，性能不足时可选择标准画质。完整说明见 ZIP 中的中文打开说明和仓库 README。

新版船体按 150 km 与星球共用公里比例。跃迁末段直线减速，星球从远处的小圆盘持续放大，光效逐渐淡出；保持进入末段的朝向与翻滚，不自动调平或转向地平线。抵达位置保留出发时相对目标的方位，岩石行星通常抵达约 1100 km 高度。大气、云影和地表纹理已细化，网格细节与渲染分辨率自动适应 60 Hz 帧预算。

`voyager-flight.zip` 为阶段 03 自由航行包，`voyager-solar-system.zip` 与 `voyager-earth.zip` 为前两阶段观测存档。新版大气、程序化地表与着陆系统在 `voyager-warp.zip`。

靠近岩石行星或卫星后按 L 连续下降到地表；落地后 L 或 R 起飞，空格或手动操纵可中止辅助。恒星和巨行星不能地表着陆。地形与大气属于游戏模拟，并非真实测绘或天气；地表状态支持保存恢复。

地球 100 km 已进入稀薄大气，蓝色散射与地平线辉光随下降逐渐增强，星空逐步淡出；晨昏出现暖色散射，夜面保持暗空。近处天空和远处大气共用实际公里尺度，外部镜头跟随飞船高度。视觉密度为参考《无人深空》的美术参数，飞行阻力仍按稀薄高空空气计算。
