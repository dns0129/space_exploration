# 手动航速、分层天空与独立星球内渲染

**最新 `voyager-warp.zip` 使用全部 43 个天体的统一 16K 表面材质：从远处拉近、进入地表和徒步时保留相同地貌。** 落地离舱、不同重力跳跃、手动航速、轨道启动、星际档位、蓝天和多层云继续可用。火星和月球保留原生 8K 表面影像与 4K 兼容版本；基础贴图、AI 材质、高度数据和分块生成程序均随包提供。

地球使用原生 16K 日面分块、8K 云层/夜景与 **1024 × 512** GEBCO 高度场及海陆分类；这些高度同时用于轨道模型、地表网格和碰撞。“超清”最多驻留四块细节，进入地表继续使用。16K 分块只要求显卡支持 2064 像素，8K 全球影像尺寸受限或加载失败时仍可使用 4K 底图上的原生 16K 分块。触屏和低内存设备使用 4K。旧地球地形 PNG 和旧半人马座天空图片留在仓库来源记录中，最新 ZIP 不重复携带未使用图片。

其余天体近观时将原有 2K/4K/8K 底图或原创程序底色与新增 AI 材质和程序细节合成为 **16384 × 8192（16K）增强表面**。桌面高清或超清画质、视角距天体中心不超过三倍半径时，按视角在 GPU 上生成细块，显卡需要支持至少 2064 像素的纹理。每块有效区域为 **2048 × 2048**，四周各有 8 像素边界，最多驻留四块。岩石颗粒、冰裂缝、云丝与恒星颗粒为美术细节，实测底图的原生分辨率保持不变；没有全球影像的天体继续使用概念图，谷神星保留程序底色。基础素材与生成程序均内嵌，断网也能生成细块。导航现有 43 个天体与一座空间站，空间站使用独立结构模型。

**34 个固体天体** 共享远近地形与碰撞高度。地球以外使用 **512 × 256** 的影像明暗推断高度或固定程序坑场，属于美术示意；土卫一影像中的 Herschel 大坑保留几何坑底和坑沿。远处和近处的纹理缓存采样相同材质函数，画质只改变细节过滤和网格密度。旧版有效的着陆、徒步存档恢复时会贴合新地表，保留表面方向和离地高度。

下载 **`voyager-warp.zip`**，完整解压，将 `voyager-warp.html` 拖入 Chrome 或 Edge。点击顶部“自由航行”，按 W 出发，方向键转向（鼠标不操控飞船），Shift 加速，空格刹车，C 切换视角，J 启动跃迁引擎，O 启动近地轨道引擎，L 自动着陆/起飞/中止。手机使用触屏驾驶按钮。

恒星系统菜单支持太阳系、半人马座 α 与参宿四；可访问南门二 A/B、比邻星及比邻星 b/c/d，跨系统跃迁、光年距离和背景自动切换均可离线使用。c/d 为候选，系外行星地表是探索示意。

参宿四目前仅包含一颗红超巨星，使用原生 8K（8192 × 4096）表面艺术示意；触屏、低内存或无法支持 8K 的 GPU 加载原生 4K（4096 × 2048）版本。可近观、锁定、跃迁并保存/恢复，不可着陆，暂未加入行星或伴星。

卫星导航包括月球及四颗巨行星的 25 颗主要卫星，共 35 个天体。大气、近地轨道、行星和星际引擎都由玩家手动选择，默认行星引擎与 100 km/s；航速输入最低 100 km/s，不设最高值。O 直接选择轨道引擎，高度、大气、朝向和安全区不再限制档位或航速，也不再阻止跃迁。引擎与航速随存档保存。刹车、实体碰撞、自动着陆和徒步继续正常工作，制动时有琥珀色减速脉冲。

独立 HTML 包含全部程序、样式与高清素材，可离线驾驶，使用本机存档。使用 8K/4K 银河背景与真实太阳系尺寸、平均日距。选择导航目标后可对准航向，或启动跃迁，经蓄能、航道和减速抵达附近，支持暂停、保存和恢复。

包内也有后端程序。安装 Node.js 24 LTS 后双击 `启动航行.bat`（Windows），或运行 `bash 启动航行.sh`（macOS/Linux），然后在本机浏览器打开 `http://127.0.0.1:3000/`。也可直接运行 `node server/server.mjs --standalone`。后端不需要安装 npm 依赖，存档保存在 `data/` 中。

浏览器需要支持 WebGL 2 并启用图形加速，性能不足时可选择标准画质。完整说明见 ZIP 中的中文打开说明和仓库 README。

新版船体按 10 km 与星球共用公里比例。跃迁末段直线减速，星球从远处的小圆盘持续放大，光效逐渐淡出；保持进入末段的朝向与翻滚，不自动调平或转向地平线。抵达位置保留出发时相对目标的方位，岩石行星通常抵达约 1100 km 高度。大气、云影和地表纹理已细化，网格细节与渲染分辨率自动适应 60 Hz 帧预算。

`voyager-flight.zip` 为阶段 03 自由航行包，`voyager-solar-system.zip` 与 `voyager-earth.zip` 为前两阶段观测存档。新版大气、程序化地表与着陆系统在 `voyager-warp.zip`。

靠近岩石行星或卫星后按 L 连续下降到地表；落地后 L 或 R 起飞，空格或手动操纵可中止辅助。恒星和巨行星不能地表着陆。地球高程为简化 GEBCO 数据，其他地形与大气属于游戏示意；地表状态支持保存恢复。

地球 100 km 已进入稀薄大气，蓝色散射与地平线辉光随下降逐渐增强，星空逐步淡出；晨昏出现暖色散射，夜面保持暗空。近处天空和远处大气共用实际公里尺度，外部镜头跟随飞船高度。视觉密度为参考《无人深空》的美术参数，飞行阻力仍按稀薄高空空气计算。

当前版本提供精细曲面飞船、43 天体固定球面材质与 16K 细块、真实 8K 银河直接采样、地球立体云层和连续曲面地表。16K 颜色材质、共享高度场和原生照片分辨率分别记录。

星球内和太空由独立场景接管，同一帧只更新当前模式。星球内暂停无关全球模型，只更新当前天体的基础影像、材质和 16K 缓存，保留相同地貌的曲面地平线；蓝天、太阳盘与云层按距离和光照渲染。

最新包新增主小行星带（谷神星导航入口）和地球上方 400 km 的科幻空间站；可观测、锁定、跃迁、保存与恢复。带区密度及空间站 120 km 跨度为游戏示意，空间站暂不支持对接。

着陆后按 **E** 离舱，**WASD** 行走、**Shift** 奔跑、**空格** 跳跃，方向键或拖动看向，**C** 切换第一/第三人称。落地并回到停泊点 **12 m** 内可按 E 返舱；低重力下跳得更高、滞空更久，极低重力有宇航服回落辅助。徒步位置、速度、视角与腾空状态随航行一起保存。
