# 巴纳德星 · 红矮星与四颗近轨道行星

新增巴纳德星及由内向外的 **d、b、c、e** 四颗行星。暖铜光球、克制日冕与四套干燥矿物地表使用原生 **8K** 原创艺术表面，紧凑设备使用滤波 **4K** 兼容版。四颗行星支持观测、跃迁、放置飞船或人物、着陆、徒步与存档；轨道和地表保持统一的材质、光色与高度场。行星存在与周期依据观测，半径、地形、重力和方位为探索示意，没有实测地表影像或已确认大气。

## 回声裂隙 · 虚构脉冲星系

新增原创航区 **回声裂隙**：中央脉冲星、青金色气态巨行星维尔、有水系的塔拉萨与干燥的烬岩两颗大型岩石卫星，以及碎裂巨型行星残冕和碎裂卫星裂片。银河保留原有画风，加入不同的尘埃带、星云与星点细节。两颗完整卫星支持着陆、徒步和存档；其余四个新天体无法着陆。脉冲星视觉半径艺术放大，全部新航区参数为虚构。

行星观测站新增 **放置飞船 / 放置人物**：选好对象后点击星球上的位置，即刻停泊或开始徒步，按 Esc 取消选点。恒星、巨行星与空间站禁用放置。**相机按钮 / P** 开启摄影，画布全屏且全部界面隐藏；**Enter** 保存 PNG，**P / Esc / 双击画面** 退出，手机双击退出。可使用系统截图。




**40 个固体天体** 共享远近地形与碰撞高度。地球以外使用 **512 × 256** 的影像明暗推断高度或固定程序地形，属于美术示意；土卫一影像中的 Herschel 大坑保留几何坑底和坑沿。远处和近处的纹理缓存采样相同材质函数，画质只改变细节过滤和网格密度。旧版有效的着陆、徒步存档恢复时会贴合新地表，保留表面方向和离地高度。

从 [公开网站下载最新 `voyager-warp.zip`](https://dns0129.github.io/space_exploration/downloads/voyager-warp.zip)，完整解压，将 `voyager-warp.html` 拖入 Chrome 或 Edge。点击顶部“自由航行”，按 W 出发，方向键转向（鼠标不操控飞船），Shift 加速，空格刹车，C 切换视角，J 启动跃迁引擎，L 自动着陆/起飞/中止。手机使用触屏驾驶按钮。

恒星系统菜单支持太阳系、半人马座 α、巴纳德星、参宿四、虚构回声裂隙与暗渊黑洞，共56个目的地；可访问南门二 A/B、比邻星及比邻星 b/c/d，跨系统跃迁、光年距离和背景自动切换均可离线使用。c/d 为候选，系外行星地表是探索示意。

参宿四目前仅包含一颗红超巨星，使用原生 8K（8192 × 4096）表面艺术示意；触屏、低内存或无法支持 8K 的 GPU 加载原生 4K（4096 × 2048）版本。可近观、锁定、跃迁并保存/恢复，不可着陆，暂未加入行星或伴星。

卫星导航包括月球及四颗巨行星的 25 颗主要卫星，共 35 个天体。导航目标可收起，引擎滑条独立放在下方，五档航速为 1–100、100–1000、1000–10,000、10,000–50,000、50,000–150,000 km/s，默认 100 km/s；飞船逐渐加减速接近滑条目标。只有离实际固体地表 10 km 以内时才使用 1–1000 m/s 的低空引擎，离开后恢复保存的太空预设。低空与太空速度分别保存，旧存档兼容迁移。刹车、实体碰撞、自动着陆和徒步继续正常工作，制动时有琥珀色减速脉冲。

独立 HTML 包含全部程序、样式与高清素材，可离线驾驶，使用本机存档。使用 8K/4K 银河背景与真实太阳系尺寸、平均日距。选择导航目标后可对准航向，或启动跃迁，经蓄能、航道和减速抵达附近，支持暂停、保存和恢复。

包内也有后端程序。安装 Node.js 24 LTS 后双击 `启动航行.bat`（Windows），或运行 `bash 启动航行.sh`（macOS/Linux），然后在本机浏览器打开 `http://127.0.0.1:3000/`。也可直接运行 `node server/server.mjs --standalone`。后端不需要安装 npm 依赖，存档保存在 `data/` 中。

浏览器需要支持 WebGL 2 并启用图形加速，性能不足时可选择标准画质。完整说明见 ZIP 中的中文打开说明和仓库 README。

飞行船体按 10 km 与星球共用公里比例；离地 2 km 内平滑切换为 24 m 地表登陆艇，停泊时外部镜头可看清完整船体。跃迁末段直线减速，星球从远处的小圆盘持续放大，光效逐渐淡出；保持进入末段的朝向与翻滚，不自动调平或转向地平线。抵达位置保留出发时相对目标的方位，岩石行星通常抵达约 1100 km 高度。大气、云影和地表纹理已细化，网格细节与渲染分辨率自动适应 60 Hz 帧预算。

`voyager-flight.zip` 为阶段 03 自由航行包，`voyager-solar-system.zip` 与 `voyager-earth.zip` 为前两阶段观测存档。新版大气、程序化地表与着陆系统在 `voyager-warp.zip`。

靠近岩石行星或卫星后按 L 连续下降到地表；落地后 L 或 R 起飞，空格或手动操纵可中止辅助。恒星和巨行星不能地表着陆。地球高程为简化 GEBCO 数据，其他地形与大气属于游戏示意；地表状态支持保存恢复。

地球 100 km 已进入稀薄大气，蓝色散射与地平线辉光随下降逐渐增强，星空逐步淡出；晨昏出现暖色散射，夜面保持暗空。近处天空和远处大气共用实际公里尺度，外部镜头跟随飞船高度。视觉密度为参考《无人深空》的美术参数，飞行阻力仍按稀薄高空空气计算。



最新包新增主小行星带（谷神星导航入口）和地球上方 400 km 的科幻空间站；可观测、锁定、跃迁、保存与恢复。带区密度及空间站 120 km 跨度为游戏示意，空间站暂不支持对接。

着陆后按 **E** 离舱，**WASD** 行走、**Shift** 奔跑、**空格** 跳跃，方向键或拖动看向，**C** 切换第一/第三人称。落地并回到停泊点 **12 m** 内可按 E 返舱；低重力下跳得更高、滞空更久，极低重力有宇航服回落辅助。徒步位置、速度、视角与腾空状态随航行一起保存。

地球保留原来的原生影像和观测细节；火星、月球保留原生 8K / 4K 影像。离线包携带原有 4K 地球地形图（高画质也复用此地形图）与共享碰撞高度数据。

当前星球材质已恢复到增强升级前版本。近地表只绘制一个完整封闭球面，集中细分观察者附近的网格，不叠加地表补片、AI 材质或额外岩石。五档推进和导航保持当前版本。
