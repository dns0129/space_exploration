# 远航 VOYAGER

一个从地球开始的 3D 星际航行模拟器。当前完成**阶段 01：地球观测站**，优先建设宇宙与星球画面，后续逐步加入太阳、其他七颗行星和航行体验。

## 直接体验

在仓库的 [downloads](downloads) 目录下载 `voyager-earth.zip`，解压后将 `voyager-earth.html` 拖进 Chrome 或 Edge。独立版本内嵌全部高清素材、程序和样式，无需服务器或联网。

## 运行

需要 Node.js 22.12+ 或 24 LTS，npm 10+。无需数据库、API 密钥或后端服务。

```sh
cd /workspace/space_exploration
npm ci
npm run dev
```

开发服务默认监听 5173 端口。所有地球贴图均随仓库保存，运行时不依赖外部素材站点。

```sh
npm run build  # TypeScript 检查与生产构建，输出 dist/
npm run preview -- --port 4173  # 查看构建产物
npm test       # 桌面和移动端 Chromium 功能验证
```

测试优先使用 `/usr/bin/chromium`；也可以通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定已安装的 Chromium。未安装浏览器时运行 `npx playwright install chromium`。测试通过 SwiftShader 提供无显卡环境中的 WebGL 2，并检查实际渲染像素、相机、图层、响应式布局和加载失败后的重试。软件渲染测试不代表独立显卡上的帧率。

## 当前功能

- 4K 地表、4K 城市夜景、4K 独立云层、地形细节和海洋高光。
- 按日照方向混合昼夜影像，添加大气边缘微光，生成带银河星带的宇宙背景。
- 鼠标或触屏环绕与缩放；全景、近地与夜景三个相机预设。
- 云层、大气、星空开关；自转暂停与演示速度；高清和标准渲染画质。
- 相机观测高度、全屏、键盘操作指南、加载进度与失败重试。
- 桌面与移动端布局，减少动态效果偏好默认暂停自转。

键盘：方向键环绕，`+` / `-` 缩放，空格暂停自转，`R` 回到全景，`H` 操作指南。

## 范围与下一阶段

这一版只实现地球。导航中的太阳和其余七颗行星明确标记为后续建设，尚不可进入；航行模拟尚未实现。地球自转使用加速演示，没有模拟轨道力学、重力或飞船动力学。相机距球心的距离按地球平均半径换算为观测高度，近地模式是轨道观察视角，不是地表漫游。

地轴倾角、平均半径与太阳距离用于场景和信息展示，恒星位置为程序生成。云图和夜间灯光为静态素材，不是实时气象或观测数据。

## 项目结构

- `src/earth-scene.ts`：Three.js 渲染、光照与大气着色器、相机和资源管理。
- `src/main.ts`：中文观测界面、控制、加载与错误状态。
- `src/solar-system.ts`：地球参数和未来太阳系导航数据。
- `public/textures/`：本地高清贴图，来源见 [ASSETS.md](ASSETS.md)。
- `tests/earth.spec.ts`：浏览器功能和实际渲染验证。

未来增加星球时可以扩展天体数据并拆分天体工厂；当前没有引入不必要的物理引擎。
