# 远航 VOYAGER

一个从地球开始建设的 3D 星际航行模拟器。当前完成**阶段 02：太阳与八颗行星观测模型**，可在九个天体之间切换，环绕查看各自的地表、云带、风暴和环系。

## 直接体验

下载 [太阳系离线游戏包](https://github.com/dns0129/space_exploration/raw/refs/heads/main/downloads/voyager-solar-system.zip)，解压后将 `voyager-solar-system.html` 拖进 Chrome 或 Edge。程序、样式和全部地球高清贴图已内嵌，其他天体使用程序化材质，无需服务器或联网。浏览器需要支持 WebGL 2 并开启图形加速。

若下载链接没有直接保存文件，可打开 [文件页面](https://github.com/dns0129/space_exploration/blob/main/downloads/voyager-solar-system.zip) 点击下载按钮。旧的 `voyager-earth.zip` 保留为阶段 01 存档；新增天体请使用太阳系版。

## 运行

需要 Node.js 22.12+ 或 24 LTS，npm 10+。无需数据库、API 密钥或后端服务。

```sh
cd /workspace/space_exploration
npm ci
npm run dev
```

开发服务默认监听 5173 端口。可以通过 `#planet=saturn` 等地址片段直接打开对应天体。所有素材随仓库保存，渲染不依赖外部素材站点。云环境的内部地址仅供开发验证；本地体验使用上面的离线游戏包。

```sh
npm run build                 # TypeScript 检查与生产构建，输出 dist/
npm run preview -- --port 4173 # 查看生产构建
npm test                      # 桌面与移动端浏览器测试
npm run export                # 生成独立 HTML 和太阳系 ZIP
npm run test:offline           # 导出并在断网浏览器上下文验证全部天体
```

导出结果：`dist-standalone/voyager-solar-system.html` 与 `downloads/voyager-solar-system.zip`。导出不需要 Python 或额外压缩软件。

测试优先使用 `/usr/bin/chromium`；也可以通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定 Chromium。未安装浏览器时运行 `npx playwright install chromium`。无显卡测试使用 SwiftShader 提供 WebGL 2，并检查实际渲染像素、图层画面变化、相机、响应式布局、加载失败重试及切换时的异步请求。软件渲染测试不代表独立显卡上的帧率。

离线测试在断网浏览器上下文执行导出的完整 HTML，并确认九个模型实际渲染、没有 HTTP 请求或浏览器错误。云环境的浏览器策略阻止 `file://` 导航，因此该测试未验证本机双击打开的系统行为；普通浏览器可以直接打开独立 HTML，受组织策略管理的浏览器需遵循其文件访问设置。

## 当前功能

| 天体   | 模型外观                                         |
| ------ | ------------------------------------------------ |
| 太阳   | 发光等离子体纹理、太阳黑子、渐隐日冕和日珥       |
| 水星   | 灰色岩石、不同大小的陨石坑和地形光照             |
| 金星   | 金色厚云与底层岩石，可关闭云层查看地表           |
| 地球   | 4K 地表、城市夜景、独立云层、地形与海洋高光      |
| 火星   | 赤色地形、暗色区域、极冠和薄大气                 |
| 木星   | 交错云带、大红斑与扁球外形                       |
| 土星   | 金色云带、细密环系、卡西尼缝隙及环与行星间的阴影 |
| 天王星 | 青蓝大气、弱云带与大幅倾斜的自转轴               |
| 海王星 | 深蓝云带、暗色风暴与独立薄云                     |

九个天体共享星空、鼠标或触屏环绕、缩放、全景与近观预设、自转暂停和速度、高清与标准画质、全屏和键盘指南。地球增加夜景预设；其余行星可观察背光面。界面只显示当前天体支持的图层，太阳可切换日冕，土星可切换环系。

信息面板随天体更新半径、太阳距离、公转周期和轴倾角；太阳显示表面温度和光谱类型。场景缓存模型及地球贴图，切换时复用渲染器，较早的加载请求不会覆盖当前观测天体。返回地球保留原有 4K 外观与控制。

键盘：方向键环绕，`+` / `-` 缩放，空格暂停自转，`R` 回到全景，`H` 操作指南。手机单指环绕、双指缩放，在“观测设置”中调整图层和画质。减少动态效果偏好默认暂停自转。

## 范围

本阶段优先建设星球画面，尚未实现飞船、引力、轨道力学或地表漫游。各天体采用独立展示比例，未在一个真实比例的太阳系场景中排列。自转为加速演示，观测高度按当前天体平均半径换算。

地球使用静态影像；太阳及其余行星的地形、云带、风暴和环系由着色器生成，为艺术化模型，并非实测影像或实时气象。恒星位置也由程序生成，光照与大气效果经过简化。

## 项目结构

- `src/planet-scene.ts`：Three.js 场景、地球影像模型、相机、模型缓存与 GPU 资源管理。
- `src/planet-models.ts`：太阳和七颗行星工厂、程序化着色器、土星环与太阳日珥。
- `src/solar-system.ts`：九个天体参数、信息和可用图层。
- `src/main.ts`：中文界面、天体导航、观测控制、加载与错误状态。
- `public/textures/`：地球本地高清贴图，来源见 [ASSETS.md](ASSETS.md)。
- `tests/`：桌面、移动端功能与实际渲染验证。
- `scripts/`：可重复生成和验证独立离线游戏包。
